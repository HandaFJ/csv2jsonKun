# CSV to JSON 変換くん

Deno + Vite + Vue で構築された、リアルタイムCSV→JSON変換Webアプリケーションです。

## 主な機能

- **リアルタイム変換**: 入力・編集と同時にJSON出力が即時更新されます。
- **キーの正規化と警告検知**:
  - 空白のトリム、連続スペースのアンダースコア化、空ヘッダーの補完、重複キーへの連番付与を自動で行います。
  - 先頭ゼロ（`007`）、16進数（`0xFF`）、`NaN`、`Infinity` など、JSON仕様上は有効でも下流のシステムで数値として誤解釈されやすいキーを検知し、赤字ハイライトおよび警告通知で知らせます。
- **安全な型推論**: JSONの厳密な数値文法に一致する値のみを数値化し、真偽値（`true`/`false`）や `null` を自動変換します。
- **シンタックスハイライト**: キー、文字列、数値、真偽値、nullを色分けして表示します。
- **列数不一致の検知**: ヘッダーの列数とデータ行の列数が異なる場合、警告通知を表示します。

## 技術スタック

- Deno
- Vite
- Vue 3 (Composition API / TypeScript)

## セットアップと起動

1. 依存関係のインストール

```bash
deno install
```

2. 開発サーバーの起動

```Bash
deno task dev
```

3. ブラウザで表示されたローカルURL（例: http://localhost:5173 ）にアクセスします。

## オプション設定

- キーの正規化: ヘッダーの空白整形、空キーの補完、重複回避の有効/無効を切り替えます。
- 型自動変換: 数値、真偽値、nullへの自動変換の有効/無効を切り替えます。
- インデント: 出力JSONのフォーマット（2スペース / 4スペース / 圧縮）を選択します。
